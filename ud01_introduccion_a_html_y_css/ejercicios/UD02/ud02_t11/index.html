CAPÍTULO 1

Etiquetas HTML

Para comenzar a crear nuestras páginas web lo único que tenemos que hacer es ir componiendo las diferentes etiquetas HTML del documento. Una etiqueta HTML es un término rodeado por un signo de "menor qué" y otro de "mayor qué".

Estructura básica de una página

Las páginas web mantienen una estructura muy sencilla que debemos respetar para que los navegadores sean capaces de comprenderla. No podemos comenzar nuestra página con una etiqueta de párrafo, por ejemplo, sino que debemos indicar qué tipo de página estamos generando, qué información adicional llevará y dónde comienza el contenido que debe ser mostrado.

CAPÍTULO 2

Títulos y párrafos

El lenguaje HTML es muy cuidadoso con la organización de información, por lo que lo primero que debemos conocer es cómo estructurar los títulos y cómo definir los párrafos de texto.

Párrafos

Las etiquetas "p" y "/p" se emplean para definir un bloque de texto que se comporta como párrafo. Normalmente no dejaremos nunca una única porción de texto suelta en la página web, sino que la rodearemos con dichas etiquetas.

Títulos

Las etiquetas desde "h1" hasta "h6" se utilizan para definir un texto como título, indicando que es un encabezado que queremos destacar sobre el resto del texto. Tenemos 6 opciones para definir diferentes títulos, de mayor a menor importancia. Una página web bien diseñada contará con estos encabezados para definir los distintos apartados de texto, con sus diferentes niveles.
